# A-Trello-like-task-management-web-app

A Trello-like task management web app built with **React** and **Tailwind CSS** for organizing tasks into boards and lists.

## ✨ Features
- Create, update, Drag & drop and delete tasks  
- Organize tasks into multiple boards  
- Responsive UI built with Tailwind  
- Easy and intuitive task management (Trello-like)
